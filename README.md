# PhishGuard – ML Based Phishing URL Detector

**PhishGuard** is a Machine Learning based phishing detection system that analyzes URLs and provides a risk score indicating whether a link is **phishing or safe**.
This project includes a **Website Interface** and a **WhatsApp Bot** designed to help users quickly verify suspicious links.

🌐 Live Website: https://urlphishingdetector.netlify.app/

---

## 📌 Project Overview

PhishGuard was developed to simplify phishing detection using automation and intelligent analysis.
Users can submit a URL and receive a detection score based on trained Machine Learning models and additional verification tools.

The system was trained and evaluated using **45,000+ datasets** to improve detection accuracy and reliability.

---

## 🤖 WhatsApp Bot (Project Concept)

The WhatsApp bot was designed to allow users to send any URL directly on WhatsApp.
After receiving a link, the bot would:

* Analyze the URL using the ML model
* Verify results using additional security tools
* Generate a phishing risk score
* Respond with detection results (Safe / Phishing + Score)

⚠️ Note:
The WhatsApp bot is currently **not active** on the public website because the required panel/API access is not available. The project demonstration is shared for educational and portfolio purposes.

---

## 🌐 Website Features

* URL phishing detection with scoring system
* Machine Learning based analysis
* Additional verification before generating results
* Simple and user-friendly interface

The website performs the same detection workflow as the bot, allowing users to test links directly through the browser.
